# 试玩美术素材核对

核对入口是试玩分支的 `index.html`。游戏用 Canvas 合成画面，因此需要区分 Canvas 贴图、贴图加程序细节、以及完全由代码画出的物件。

| 部分 | 当前实际使用 |
| --- | --- |
| 剧情及无尽的远景 | 街区、雨夜、雪镇、码头、黄昏、冰港六张独立插画。15 个剧情章节按主题使用对应背景，部分章节共用底图并叠加不同色调和天气。旧的代码天空与天际线在图片加载前作为备用画面。 |
| 普通剧情楼房 | 真实楼房图集，重复铺成楼层。大部分剧情楼型与无尽夜区源自第一章同一套图片，程序换色、调整窗格的排布，并叠加檐口、雨棚、雪沿、霓虹和邮灯。 |
| 海港与街区旗杆 | 木栈桥、系缆桩和邮差旗杆均用图片。栏杆下方的水波和冰片由代码绘制。 |
| 角色与换装 | 15 套角色的四种基本姿势使用贴图。片尾挥手用角色贴图的头、腿和弹簧杆，手臂、手掌和躯干仍用 Canvas 画。 |
| 包裹、道具与商店 | 包裹、商品图标、角色预览和主菜单主要按钮使用贴图。部分效果与图片未加载时的备用图形由代码绘制。 |
| 陷阱与终点 | 移动平台、弹跳垫、巡逻狗、收件人使用贴图。晾衣绳是贴图和代码混合，支柱及衣物仍用 Canvas。第 1 章的收件箱使用贴图，其他章节交付门和地垫仍主要靠代码。 |
| 仍由代码绘制的实体 | 窄砖墩、路灯、风扇机身和叶片、屋顶通风口。 |
| 仍由代码绘制的动态层 | 轨迹、落点靶标、蓄力与平衡读数、雨雪风雾、闪电、海浪、落地粒子和片尾邮戳。 |

独立美术图片位于 `art/game/painted-scenes/`，同样的 WebP 已内嵌在游戏 HTML 中，供单文件试玩和打包入口使用。
