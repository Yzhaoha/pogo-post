# 蹦蹦快递 · 微信 / 抖音小游戏版

## 一句话
网页版 `index.html` 的游戏代码原样搬进小游戏，只换了 4 块：平台适配、界面（全部改成画在画布上）、广告和触屏、启动。改网页版的玩法以后，重新跑一次打包，小游戏版就跟着更新。

## 文件
- `mini/prelude.js`：把游戏用到的浏览器接口（window、document、存档……）换成 `wx`（微信）/ `tt`（抖音）的接口，并算出状态栏和右上角胶囊按钮占的位置。
- `mini/ui.js`：标题页、关卡、换装、暂停、过关、失败、每日礼物、提示框、启动时的「健康游戏忠告」，全部在画布上画；商店图标是网页版 SVG 的画布版。
- `mini/sdk.js`：激励视频（复活、跳关、商店 +60 金币）、插屏（关卡之间，开局 1 分钟内不放，2 分钟最多一次）、右上角分享、触屏。
- `mini/boot.js`：游戏名改成「蹦蹦快递」，固定中文，顶部界面避开胶囊按钮。
- `mini/preview.html`：浏览器里的假微信环境，用来不装开发者工具也能看效果。
- `tools/build_mini.py`：打包。

## 打包
```
python3 tools/build_mini.py
```
生成：
- `dist/wechat/`：用**微信开发者工具**「导入项目」打开这个文件夹（现在 AppID 是游客 `touristappid`，注册好以后换成自己的）。
- `dist/douyin/`：用**抖音开发者工具**打开这个文件夹，填自己的 AppID。
- `mini-preview/`：浏览器预览（推到 main 以后是 https://yzhaoha.github.io/pogo-post/mini-preview/ ）。电脑上按空格或点画面都能玩。

## 上线前要填的东西
1. **AppID**：`dist/wechat/project.config.json`、`dist/douyin/project.config.json`（开发者工具里填也行）。
2. **广告位 ID**：开通流量主（微信要累计 500 个独立访客）以后，在后台建「激励视频」和「插屏」广告位，把 ID 填进 `mini/sdk.js` 顶部的 `AD_UNITS`，再打包一次。
   没填之前：复活和跳关免费给，商店不显示「看广告 +60」，关卡之间没有插屏。

## 和网页版的区别
- 只有中文，没有语言选择；只有竖屏。
- 没有 Poki / CrazyGames 的接口；存档用小游戏自己的存储（和网页版不互通）。
- 小游戏没有网页元素，所以界面重画了一遍，样子和网页版尽量一致。

## 没验证过的（只在浏览器假环境里测过）
- 真机和两个开发者工具里还没跑过。最可能出问题的是声音：游戏的声音全是代码合成的（WebAudio），微信有 `wx.createWebAudioContext`；抖音如果没有对应接口，就会没声音，其他照常。
- 抖音胶囊按钮的位置接口（`getMenuButtonBoundingClientRect` / `getMenuButtonLayout`）都做了兜底，拿不到就按状态栏高度 + 4 像素算。
