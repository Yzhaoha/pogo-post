## 已定（原"待新对话决定"三项）
- **关卡数**：30 关 / 3 章，每章第 10 关是大关（👑）。第 1 章「阳光街区」（屋顶、弹床、晾衣绳、狗；纸箱、易碎件、蛋糕），第 2 章「大风码头」（风、风扇、超长件、活鸡），第 3 章「雨夜高楼」（雨天打滑 + 全部混合）。
- **蓄力**：按住时长。空格 / 鼠标 / 单指都是同一个键：地上按住蓄力、松开起跳；空中按住身体前倾。理由：Poki 要求键盘能玩，下拉手势没法映射到键盘；头部物理关卡游戏都是按住类。
- **无尽模式 / 每日挑战**：首发都不做。单键物理关卡的无尽要程序化地形，手感难保证。每日挑战放 v1.1 作为内容更新（按日期种子从已通关关卡里抽一关 + 随机包裹组合 + 限时），引擎已能支持。

### 玩法与数值（都在文件开头的常量里）
- 起跳速度 V0=380 + V1=480 × 蓄力（蓄满 0.85 秒），固定起跳角 0.48 rad。平地距离：不蓄 ≈59，蓄满 ≈303。
- 起跳后身体会后仰：自然落地角 ≈ −0.6 × 蓄力；空中按住每秒加 7.5 rad/s² 的前倾。落地角 <0.12 = 完美，>0.42 = 重落地（晃 + 易碎件裂），>0.95 = 脸着地（失败）。
- 包裹塔：一个摆角 psi（弹簧 + 阻尼 + 重力），超过 0.62 掉最上面一件。落地时的倾角、水平速度、冲击都会踢它。
- 包裹：纸箱；易碎件（重落地第一次裂、第二次碎）；蛋糕（站立时总倾角 >0.5 就滑掉）；活鸡（随机扑腾）；超长件（风和风扇 ×2.5、空气阻力）。后两种是第 2 章用的，已实现未上关卡。
- 关卡元素：屋顶平台、弹床（反弹速度 ≥1150）、晾衣绳（勾走绳子以上的包裹，身体碰到 = 失败）、狗（来回巡逻，碰到 = 失败）、风扇区、全局风、雨天（落地滑行）。
- 失败：掉下去、撞墙、脸着地、被狗咬、被晾衣绳绊、包裹掉光。失败瞬间所有包裹炸开 + 纸屑 + 慢动作 + 镜头推近 + 一句旁白吐槽（每种失败 3 句）。
- 星星：1 送达 / 2 一件不掉 / 3 在规定时间内。
- 规定时间（PAR 数组）= 机器人最优时间 × 1.35 + 2 秒，向上取整。

### 关卡数据格式（LEVELS 数组）
`plats:[[x,宽,顶部高度]]`（第一个是起点，最后一个是收件人家）· `tramps:[[x,宽]]` · `ropes:[[x1,x2,高度,下垂]]` · `dogs:[[x1,x2,速度]]` · `fans:[[x,y,宽,高,力]]` · `wind` · `rain` · `pk:[包裹，从下到上]` · `tip` 首次提示 · `boss`。
- 晾衣绳经验值：最低点 ≥ 平台高度 + 96 + 包裹总高 + 45，否则站着就会被勾。

### 机器人验证（2026-11-13）
- `__pp.solve(i)`：确定性模拟 + 束搜索（每步枚举蓄力 0–1、空中按住的起止时间、等狗的时间），10 关全部能通、不掉件。最优时间 9.8–15.4 秒。
- `__pp.robust(i, plan, 噪声, N)`：每一跳加人手误差（蓄力 ±0.04、按住时机 ±0.06 秒）。单次尝试通关率：第 1–4、9 关约 80–90%，第 6–8 关约 50–57%，第 10 关约 78%；第 5、8、9、10 关的晾衣绳最容易掉件。
- `__pp.autoplay(plan)` 把机器人方案按真实输入回放到游戏里，时间和模拟完全一致。
- 测试脚本（Playwright + /usr/bin/google-chrome）：tools/test-solve.js（解全部关卡）、test-robust.js、test-play.js（回放 + 截图）。`index.html?lvl=N` 直接进第 N+1 关。

### Poki 接入（已用假 SDK 测过调用顺序）
- init → gameLoadingFinished → 才开始第一关（首次打开直接进第 1 关，就是教程）。
- gameplayStart/Stop：开局、暂停/继续、切后台、失败、过关都正确上报。
- commercialBreak 只在「下一关 / 重来」之前，本次会话第一局之前不放。
- rewardedBreak：失败后「从这里再来」（回到上一个落脚点，包裹恢复成那时的样子，每关一次），同一关失败 3 次后出现「跳过这关」。
- Esc / P 暂停，M 静音，R 重来；空格不会滚动页面。手机单指点按。
- 测得顺序：loaded > start > stop > rewarded > start > stop > commercial > start > stop > commercial > start。
