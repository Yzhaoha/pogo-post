# 新游戏立项简报：弹簧快递（Pogo Post）

2026-11-13 立项。三款新游戏之一（另两款：最后一块饼干、地牢保洁公司），各自在单独对话里开发。开发进度见 claude/弹簧快递-开发交接.md。

## 定位
- 类型：单键物理闯关，单人
- 首投平台：**Poki**（打算独占，物理关卡类在 Poki 长期霸榜，如 Drive Mad）
- 一句话：你是踩弹簧高跷送快递的小哥，头顶叠着一摞包裹，跳到收件人门口，一件都不能掉。

## 核心玩法
- 按住压弹簧（蓄力），松开起跳；空中可以微调身体倾角
- 落地角度和力度决定头顶的包裹塔晃不晃，晃过头就散
- 包裹有特性：易碎件、活鸡（自己会动）、蛋糕（不能倒）、超长件（挡风）
- 关卡元素：屋顶、晾衣绳、狗、风扇、弹床、雨天打滑
- 每关最多 3 星：送达 / 不掉件 / 时间
- 失败瞬间包裹天女散花，要做得很搞笑（传播点）

## 画风
- 扁平矢量配粗描边，明亮卡通；Canvas 2D
- 要精致：统一线宽、统一色板、阴影和挤压拉伸动画，不能像几何原型

## 可复用
- 捏捏叠叠乐：叠塔晃动物理、关卡 / 星星 / 章节结构、盲盒图鉴、签到、Poki SDK 接入
- Burnt Again：平台跳跃手感、旁白式搞笑反馈

## 平台硬性要求
- 打开即玩，第一关就是教程
- Poki SDK：gameLoadingFinished、gameplayStart/Stop、commercialBreak 只在下一关 / 重试之前、rewardedBreak（复活、跳关）
- Esc / 空格暂停（Poki 对键盘游戏的要求）；手机单指点按
- 包体小（单个 index.html），不发外部请求
- 11 种语言（en fr it de es tr zh ja ko pt ru）

## 工作流规则（用户规定）
- 在 GitHub 建测试仓库，公共测试链接用 GitHub Pages
- 提交表单不选任何 AI 相关选项

## 已决定（2026-11-13）
- 关卡数量：**30 关 / 3 章**，每章第 10 关是大关。第 1 章阳光街区、第 2 章大风码头、第 3 章雨夜高楼。
- 蓄力方式：**按住时长**（空格 / 鼠标 / 单指同一个键；空中按住 = 前倾）。下拉手势映射不到键盘，不用。
- 暂停：空格是跳跃键，所以暂停用 **Esc / P** 和屏幕左上角暂停按钮；切到后台自动暂停。
- 无尽模式：**不做**。每日挑战：**首发不做，v1.1 作为内容更新加**（按日期种子抽已通关关卡 + 随机包裹 + 限时）。
