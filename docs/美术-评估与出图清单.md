# 美术评估与出图清单（2026-11-18）

## 对照了什么
CrazyGames 的 jumping / physics / one-button 三个分类页、Poki 首页和 skill 页的封面墙；以及几款同类（单键、2D、物理）游戏的详情页实际画面：Knockabout Golf、Office Chair Parkour、Home Flip、Wacky Flip、Tube Jumpers、Yeetcat。

## 结论
- **游戏内画面：够用，不是短板。** 同类已上线游戏的实机画面很多比我们朴素（纯色地面 + 小人）。我们有统一描边、统一配色、角色动画、三套场景。
- **最大的差距是封面。** 平台上每一款游戏都有一张精心画的封面：大角色特写 + 粗体游戏名 + 高饱和背景。我们现在没有封面图。封面决定玩家点不点，也是审核第一眼看到的东西。
- **其次是标题页。** 现在是一块白面板加文字，没有游戏名的美术字（logo）和主视觉。
- 再次（可选）：主角可以更有记忆点（表情更大、轮廓更特别）；背景楼房重复感偏强。这两项用代码改，不需要出图。
- 说明：CG 之前 5 次拒信都是通用理由，无法确认是不是美术导致的，以上只是和已上线游戏对比得出的差距。
